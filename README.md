# KSPVE-Reworked

KSVPE-Reworked is a fork of the original KSPVE. This fork is made to be less bloated, have no unneccesary features, be further optimized, and less vibecoded (will accomplished by slowly rewriting portions without AI).

---

Goals:

- Optimize the mod
- Remove unnecessary features & de-bloat the mod
- Unify the names
- Make the codebase more organized
- Rewrite the code slowly to make it less / not vibecoded
